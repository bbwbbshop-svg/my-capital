Мой капитал 0.1
Windows: распакуйте архив, откройте index.html. Для полноценного PWA разместите все файлы на HTTPS-хостинге (например GitHub Pages). На iPhone откройте адрес в Safari, Поделиться → На экран «Домой». Данные разных браузеров не синхронизируются. Не очищайте данные сайта без резервной копии JSON. CSV открывается в Excel. Не публикуйте резервные копии на хостинге. Для локального теста при наличии Python: python -m http.server 8000 в папке приложения, затем http://localhost:8000.
